Drop your pictures in this folder. That's it - no code changes needed.

Naming:  <name>_<number>.<jpg|png|webp>

    piccolo_1.jpg   ->  aura --piccolo -1
    piccolo_2.jpg   ->  aura --piccolo -2
    goku_1.png      ->  aura --goku -1      (a brand new flag appears by itself)

A file with no number (piccolo.jpg) counts as number 1.
Names must be lowercase letters/digits and start with a letter.

Tip: crop the picture tight on the face before adding it, or set a crop
for it in src/aura/tuning.py.
